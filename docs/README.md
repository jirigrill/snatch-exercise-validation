# docs/ index

Start with [`STATUS.md`](STATUS.md).

**File numbers are ticket numbers, not a sequence.** `research/12-…` and `results/12-…` are different tickets (#12 is the walking skeleton, the research note numbered 12 is the feasibility grill), so the same number appears in both folders. Find a ticket's page by its result link in `STATUS.md`.

| File | What |
|---|---|
| `STATUS.md` | Plan, pass rules, ticket states, next step |
| `recording-protocol.md` | Camera set-up, spike session, gate 1 rule |
| `clip-log.md` | Every clip with role and caveats; `clip-log-sheets/` has a contact sheet per 2026-10-01 clip |
| `sensitivity-log.csv` | Per-lift log of the spike session |
| `paywalled-papers.md` | Papers cited but not in `papers/` |
| `papers/` | Papers read for the research notes |
| `research/` | Market, feasibility and design research |
| `results/` | Measured results, one file per ticket |
