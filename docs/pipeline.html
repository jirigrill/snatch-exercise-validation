Example clip: 20261001_3_jiri_v1_powersnatch_5kg_1rep_success_0deg (10.4 s, 2498 frames at 240 fps). Click any box, file or event: the panel on the right explains it.

The whole pipeline

Times are for the example clip (2498 frames) on this Mac. ⓪ (new) finds the lifter once; ① reads it. ① and ② don't depend on each other. ③ and ④ need both. ⑤ (dashed) is new: it is only needed for clips with several reps, and lets ① skip the frames between reps.

Commands for one clip

cd prototype
clip=20261001_3_jiri_v1_powersnatch_5kg_1rep_success_0deg
uv run python scripts/extract_person.py ../vids/$clip.MOV out/$clip      # ⓪ add --overlay for a video with the boxes
uv run python scripts/extract_pose.py   ../vids/$clip.MOV out/$clip      # ① needs person.npz; add --overlay for a skeleton video
uv run python scripts/track_plate.py    ../vids/$clip.MOV out/$clip      # ②  add "ellipse" for ±30° views, "--radius 70:140" for 2026-10-05, --overlay for a plate video
uv run python scripts/analyze.py        ../vids/$clip.MOV out/$clip      # ③
uv run python scripts/compare_phases.py out/$clip                        # ④

Why 2026-10-05 failed: the camera was about 1.8× further away, so the plate looks smaller (radius ~96 px). Step 1 only looks for circles of 110–260 px, so it never saw the plate and followed the medicine balls instead. Fix: --radius 70:140. Checked on 20261005_2 (now ok) and 20261001_3 (result unchanged).
